Write the funniest one-line patch note for a bug in real life or human biology, 160 characters max. A judge compares entries two at a time and picks the funnier; the top 5 places split the $5 reward pool equally.

This entry's patch note:

> v2.7.4: fixed a memory leak where the brain kept every embarrassing moment since 2009 and replayed them at 3 a.m.

Why it wins: it is written in genuine patch-note register ("fixed a memory leak", a version number) applied to a universal human bug — the brain replaying old embarrassments at 3 a.m. "Memory leak" is real software vocabulary, so the joke lands inside the form instead of beside it, and "since 2009" and "3 a.m." are concrete details that make the scene instantly recognisable. 113 characters: every word works, no padding, one line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes exactly that one line, and nothing else, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Python 3.13, standard library only, fully deterministic.
